🎵 Music Calculator

A simple and interactive Music Calculator built using HTML, CSS, and JavaScript. This project combines basic calculator functionality with a music-themed user interface.

🚀 Features

- Addition, subtraction, multiplication and division
- Percentage calculation
- Clear ("AC") button
- Delete ("DEL") button
- Decimal calculations
- Play and Pause music controls
- Responsive design
- Music-themed UI

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Audio HTML Element

📂 Project Structure

music-calculator/
│
├── index.html
├── style.css
├── script.js
└── music.mp3

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure the "music.mp3" file is inside the project folder.
4. Open "index.html".
5. Run the project using Live Server.
